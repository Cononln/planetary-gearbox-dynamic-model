# 故障脉冲相位对齐：可编程实施流程 V1

本文件将创新方案转成实现规格。配套配置为 `../configs/event_alignment_v1_plan.json`，保留最初方案设置供审计。后续已完成首轮 Python 实现和 BL/PF50 探索性内部留出计算；实际执行配置与差异以结果目录的 `runtime_config.json` 和 `真实数据实现报告.md` 为准。本方案中的全部扩展/对照并非均已实现，不能把方案条目当作已验证结果。当前版本改善 PF50 包络集中程度，但未通过有符号故障脉冲波形对齐验证。

## 一、第一版具体要交付什么

输入现有 BL/PF50 的三通道振动，输出每个故障候选事件的三个时移、可信度、校正前后波形、SVD/TSA 结果和公平对比表。算法主体以振动为输入；编码器另供运动相位评分。

第一版核心为**故障事件候选匹配 + 公共残余时移/周期相对时延的约束估计**。运行中保留完整的多通道约束。额外振铃相位补偿有单独的进入条件和消融接口，默认关闭。

流程：

```text
三通道原始振动
  ├─ 5120 Hz 运动支路 → 多谐波粗运动相位 φm(t)
  └─ 51200 Hz 冲击支路 → 带内能量与相邻啮合背景比较
                 ↓
理论事件递归 + 开发段初始相位估计
                 ↓
每事件、每通道保留 3 个候选峰与未检出选项
                 ↓
三通道事件匹配 ↔ 公共残余时移 + 周期相对时延拟合
                 ↓
冻结路径模型，在后续事件上预测/校正局部时移
                 ↓
相位评价 → 局部事件 SVD 降噪 → 同类事件 TSA
                 ↓
原时间轴重构 → 连续信号包络阶次谱
```

## 三、步骤 1：产生粗运动坐标

输入：低采样率三通道 `x_motion[N,3]`。

1. 在各记录校准段，从 145–190 Hz 找啮合谱峰，取得该记录的 `fmesh0`。
2. 提取 1–4 阶啮合解析分量，按现有 `pg_common_phase_frozen.m` 的可靠性加权相位增量方法得到 `mesh_phase(t)`。
3. 根据现有负结果，在校准段做均值频率锚定：扣除相对 `2π fmesh0 t` 的线性增量偏差。锚定系数只用校准段拟合。
4. 输出 `carrier_phase = mesh_phase / 84`；检查严格递增和异常相位滑移。
5. 同时保留 `2π fmesh0 t` 匀速基线。当前稳态记录上，复杂跟踪必须与它比较。

输出 `motion.npz`：`time_s, mesh_phase_rad, carrier_phase_rad, instantaneous_mesh_hz, valid_mask, calibration_bias_hz`。

通过条件：单调、无明显整周期滑移；无效区段记录为缺测。编码器版作为独立参考流程，如果振动坐标误差已大到超过后续 ±8 ms 事件搜索范围，先报告粗相位失败。编码器辅助结果可以定位问题，但不能冒充无编码器算法结果。

## 四、步骤 2：建立“超出正常啮合背景”的瞬态证据

输入：`x_impulse[N,3]` 与插值到该时间网格的 `mesh_phase`。

开发候选频带为 0.8–2.5、2–6、4–10 kHz；初值用 2–6 kHz。频带均是待验证设定，并非已认定这些频带存在故障共振。仅由校准/验证段决定最终频带，两条状态记录使用同一冻结规则。

每通道的明确计算：

1. 用有限支撑的解析带通滤波器取得 `z_j(t)`，例如 513 taps 的 Kaiser 调制 FIR；补偿固定群时延，丢弃边界无效样本。
2. 计算 `e_j(t) = smooth_0.5ms(|z_j(t)|²)`。
3. 对每个 t，找 `mesh_phase(t_q)=mesh_phase(t)+2πq` 的邻域时刻，初始 `q∈{-6,-5,-4,4,5,6}`。它们与当前点有相同啮合相位、相隔数次啮合。
4. 令 `b_j(t)=median_q e_j(t_q)`，`a_j(t)=1.4826 median_q |e_j(t_q)-b_j(t)|`。
5. 定义候选突出度：

\[
D_j(t)=\frac{e_j(t)-b_j(t)}{a_j(t)+0.05\,\operatorname{median}_{\mathrm{cal}}e_j}.
\]

分母零值应单独判为无效。D 是归一化瞬态证据，不是故障概率。

约 168 Hz 时，4–6 次啮合的间隔是 23.8–35.7 ms。采用这组邻居，是为避开初始约 20 ms 冲击核心；如果实际衰减更长，应在验证段调整。已识别事件及其有效支撑范围不能再被当作背景，需剔除，剩余邻居少于 4 个时标记该点背景估计不可靠。该邻居配置面向行星轮故障，太阳轮事件递归不同，拓展时重新生成邻居集合。

这样先减少“正常啮合也有峰”的干扰。时变路径使相邻啮合背景不完全相同，故这一步仍需要 BL 对照。

输出 `event_evidence.npz`：三通道 D、带内波形、背景可靠性和频带信息。

## 五、步骤 3：没有齿号和机械零位，如何找事件

对本轮行星轮故障假设，定义单侧接触相位

\[
\vartheta_p(t)=\phi_m(t)/31.
\]

事件 A 的名义时刻满足 `vartheta_p(t)=eta_A+2πn`。未知常量 `eta_A` 在校准段用 1° 网格搜索；先折叠 D，再用各重复事件的截尾均值评分，不能只取全记录最高峰。三通道聚合用第二高的 D 值，使单一通道的偶发大峰不独自确定初相位。

行星故障齿可能在两个接触位置产生响应。先搜 A，再在相距 0.35–0.65 个行星相对转动周期的区域搜索 B（步长 0.01 周期）。该区间只是第一版允许范围，约半周期是初始化先验，不是经过实测确认的精确接触角。

初始可用性检查：在校准段前后两半分别出现一致峰族，至少 2 个通道提供支持。A/B 都保留“没有足够支持”的结果。没有额外机械参考时，A/B 只是两条相对事件序列，不能直接断言 A 就是太阳轮侧、B 就是齿圈侧。

在每个名义事件 `t0_n` 附近：

- 搜索范围：±8 ms，并始终小于最近异事件间距的一半。
- 每通道保留最多 3 个 D 的局部峰，最小峰间距 2 ms，初始突出度门槛 3。
- 抛物线峰顶细化只提供候选亚采样时刻，不代表达到同等物理测量精度。
- 保留未检出选项；不把每个窗口都强行补成一个故障峰。
- 原幅值的冲击核心暂取 `[t0−4 ms,t0+16 ms)`，在 51.2 kHz 下是 1024 点。额外读取搜索和过渡所需的 padding。

输出 `events.csv`：`event_id, branch, nominal_time_s, carrier_angle_rad, tidal_id, recurrence_slot, candidate_times_ch1/2/3, candidate_scores, boundary_flag`。

## 六、步骤 4：真正需要新增的约束对齐器

候选峰不直接决定最终位移。最终位移由**三通道观测与相邻事件的路径规律共同估计**。

### 4.1 待估参数

对某一候选指派得到的观测时刻 `tobs_jn`，拟合

\[
t^{obs}_{j,n}-t^0_n=d_n+\tau_{j,c}(\psi_n)+\epsilon_{j,n}.
\]

`d_n` 是公共残余时移；`tau_jc` 是该类型事件随行星架角度变化的相对路径时延。它们相加为输出 `delta_jn`，单位秒。

明确的第一版路径模型：

\[
\tau_{j,c}(\psi)=b_{j,c}+h_c(\psi-\alpha_j)
-\frac13\sum_rh_c(\psi-\alpha_r)+u_{j,c}(\psi),
\]

`h` 使用 1、2 阶 sin/cos 共 4 个系数；`u_j` 使用 1 阶 sin/cos，并施加比 h 更强的惩罚。令 `sum_j b_j=0`、`sum_j u_j=0`，固定相对参考。冗余参数通过消去第三通道的自由系数和正则化处理，检查设计矩阵秩与条件数。

公共 `d` 在事件序列上做二阶平滑：对非等间距事件先算相邻速度 `v_n=(d_n−d_(n−1))/(t0_n−t0_(n−1))`，再惩罚速度变化，按时间间隔和 1 ms 初始误差尺度无量纲化。不能把 A/B 间距误当成等间距。各接触分支的路径函数分别拟合。

具体可令 `Tref=median(diff(t0))`、`sigma_t=0.001 s`，公共平滑项取 `mean(((v_(n+1)−v_n)*Tref/sigma_t)²)`；路径平滑项取 `mean(k⁴*(a_k²+b_k²)/sigma_t²)`，通道偏离项取其系数平方除以 `sigma_t²` 后的平均。观测候选代价按全部名义事件×通道的固定数量取均值，未检出代价也计入；避免因拒绝更多事件而仅通过改变分母降低目标。加极小的全系数岭项保持数值稳定，并报告条件数。

初始边界：`|d|≤4 ms`、`|tau|≤4 ms`、`|delta|≤8 ms`。这些是待开发验证的搜索设定，不是声称钢结构实际传播需要若干毫秒；估计对象包括带内响应峰的有效迟滞。

公共路径与公共残差有规范自由度。使用零通道均值约束只是指定虚拟参考，d 不能直接命名为“真实转速波动误差”。

### 4.2 候选选择与参数更新怎样循环

给每个候选构造固定代价。例：令 `p_l∝exp(min(D_l,10)/2)`，未检出质量 `p_missing∝exp(3/2)`，在同一窗口内归一化。它是算法权重而非校准概率。

每轮在当前 `d,tau` 下选择使下式最小的候选或未检出项：

\[
\rho_{1.5}\left(\frac{t_l-t_n^0-d_n-\tau_{j,c}(\psi_n)}{1\ \mathrm{ms}}\right)-\log p_l.
\]

未检出项只有预设代价，不产生时间残差。一事件至少 2 通道有可接受候选才更新其公共 d。初次运行用第二高通道证据初始化 d，路径 tau 从零开始。

固定指派后，用有边界的 Huber 回归更新 d 和路径系数，加上上述公共平滑、路径平滑、通道偏离惩罚。Python 可用 `scipy.optimize.minimize` 的 SLSQP 求解，对训练事件和密集角度网格施加线性时延界限，保存收敛标志和约束残差。

```python
initialize_event_origins_on_calibration()
d = robust_channel_consensus_initialization()
path = zero_relative_path()
for iteration in range(10):
    assignments = choose_candidates_or_missing(d, path)
    d, path = fit_bounded_robust_model(assignments)
    if objective_change < 1e-4 and assignments_unchanged:
        break
save_assignments_model_and_convergence()
```

`1e-4` 指相对目标变化。每步必须不增加同一个已明确定义的目标；若求解失败，当前事件保留未校正结果并标记失败，不静默输出“成功”。

验证段只选少量参数：初始公共平滑强度 `{0.1,1,10}`，路径平滑初值 1，通道残差惩罚初值 10。选择依据为留一通道的到达预测误差及覆盖率约束；不按最终测试谱图是否漂亮选参数。

### 4.3 三通道怎样帮助预测

拟合路径后，将 S3 留出，用当前事件的 S1/S2 候选和冻结路径推断公共 d，再预测 S3 的到达时刻。S3 当前波形只用于评分，不能再为了提高它的得分重新移动。随后轮换留出 S1、S2。

这直接回答“另外两个测点加已学到的路径规律，能否预测第三个测点的故障脉冲位置”。它比仅展示拟合后的波形重合更有说服力。

测试阶段冻结路径、频带、初相位及门槛；每个新事件只推断公共残差与候选接受状态。若只剩一个有效通道或落到未经开发覆盖的路径角区，标记缺测，不通过扩大位移范围救回得分。

拟合前检查角度覆盖：初始按 6 个 60° 区间统计，至少 4 个区间有事件支持；不满足时退到常量相对时延对照并标记周期模型数据不足。该退化结果不能作为周期路径约束的成功证据。

输出 `alignment.csv`：各事件的原候选位置、d、tau、delta、未检出标志、三种留出预测误差和边界命中情况；另存路径系数及优化历史。

## 七、步骤 5：怎样移动信号，不弄坏频谱

局部输出按 `aligned_jn(u)=x_j(t0_n+u+delta_jn)` 读取，正 delta 表示原响应较晚，需要向前对齐。使用带 padding 的带限插值；原始幅值不归一化。

一个仅说明符号的例子：名义时刻为 1.0000 s，三个到达时刻为 1.0016、1.0024、1.0008 s。虚拟均值参考给 d=1.6 ms，tau=[0,+0.8,−0.8] ms；总移位为 [1.6,2.4,0.8] ms。若这些量均被正确估计，三个响应都移向名义事件中心。这个例子不是实测结果，也不证明 d 的物理来源。

同时需要完整时间轴输出，才能看 5.4 Hz 等低频故障调制：

1. 在 20 ms 核心内使用固定事件时移。
2. 核心外用升余弦过渡至零校正，过渡长度最多 20 ms；每个事件的总支撑不超过最近事件间距的 0.8。
3. 建立 `q_j(t)=t+sum_n delta_jn*g_n(t)`，输出 `y_j(t)=x_j(q_j(t))`。
4. 对长度 L 的升余弦过渡，检查 `|delta|π/(2L)≤0.8`，使 `q'_j(t)≥0.2`。支撑重叠、映射不单调或 padding 不足时拒绝该次重构。
5. 用同一插值器处理所有基线，记录固定移位与零移位的幅值/能量误差。

**不能把截取的 20 ms 事件窗口直接首尾拼接，再把拼接谱当成原始故障频谱。** 单个 20 ms 窗口的固有频率分辨率约 50 Hz，也不能单独证明 5.4 Hz 故障线增强。低频包络谱由完整 10 s 时间块或其角域重采样计算。

输出 `aligned_events.npz`、原时间轴 `aligned_signal.npz`、`warp_valid_mask`。

## 八、步骤 6：SVD、TSA 如何接入

先在最终 SVD 之前计算相位指标，避免降噪本身造成评分一致性上升。

随后按“事件分支 × 通道 × 行星架角度组”形成事件矩阵，第一版角度组宽 60°。矩阵每行是一段 1024 点、已对齐、原幅值的冲击响应。每组至少 8 个开发事件；不足则保持带通结果并标记 SVD 未启用。

开发段建立 SVD 右奇异向量基，初始秩 3，仅在验证段比较 1/3/5。参数确定后冻结基和秩。测试波形用 `w_denoised=w V_r V_r^T` 投影，避免把几个测试事件共同做 SVD 后再把相似性当独立证据。所有比较方法按相同规则分别在自己的开发输出上建基。

先计算每个通道的同类事件 TSA。跨通道有符号融合另行检查，保留单通道结果；额外振铃相位尚未启用时，反相通道可能依然相消，这正是下一步适用性检验的内容。

与原 TPSVD 的关系：潮汐递归用于保存 `tidal_id` 和事件身份。按 21/31/84 的当前齿数，单故障行星齿与同一行星架位置的完整重复为 31 圈，标称约 15.5 s；60 s 约 3 个完整重复。第一版这里是**局部事件矩阵 SVD**，不能把它写成拥有几十个完整潮汐周期的 TPSVD。完整潮汐矩阵单独输出，样本不足时明确说明，不伪增重复数。

局部 TSA 用于展示冲击形状；原时间轴重构及其包络阶次谱用于展示故障重复率。若将局部 SVD 结果回填时间轴，按固定过渡窗重构并单独记录该操作的能量改变。

## 九、步骤 7：什么时候增加振铃相位补偿

仅用校准/验证段检查时移后的跨通道事件互谱：

- 如果残余相位接近零、局部 TSA 已改善，保持时移版。
- 如果存在跨事件可重复的近常量相位差，拟合低阶角度相关 beta，并比较留出预测的有符号 TSA；只有它带来稳定额外收益才启用。
- 如果相位随频率强烈非线性或因事件而随机变化，记录单时延/常相位模型失配；不能让每个事件自由旋转来强行同相。

扩展补偿仍只作用于选定解析频带并保持共轭对称。测试段不根据评分决定是否启用。这一扩展有独立的开关 `ringing_phase_extension.enabled`，配置初值为 false。

## 十、步骤 8：到底输出什么指标和图

主指标沿用创新方案中已明确的 ΔS：跨时间块、同类事件、相同路径角组的归一化有符号波形相干性，扣除匹配背景/错误事件假设的相干性，再计算处理前后变化。正幅值归一化仅用于评分，不按事件翻转正负号。

至少同时保存：

| 输出 | 怎样计算/比较 |
|---|---|
| ΔS | 用最终 SVD 前的留出事件；目标与控制用同等搜索自由度 |
| 到达预测误差 | 留一通道预测与该通道独立候选时刻比较；多义峰单列，不冒充真值 |
| 已知位移 RMSE | 用控制信号/注入扰动的真值计算；编码器只能评运动角，不评传播时延 |
| 事件覆盖率 | 接受的事件/区间内全部理论候选事件；同时给共同事件掩码和覆盖率相配对比 |
| 原幅值相干能量 RE | 检查评分副本改善是否对应真实 TSA 能量保持 |
| 故障频率族/背景 | 原时间轴包络角域谱，单事件阶次 84/31 及二倍家族；不是物理 SNR |

负对照：BL、同啮合相位的背景位置、错误事件阶次。错误阶次初值为目标的 0.85/1.15 倍，运行前检查不落入已知另一故障族；每种假设执行相同校准与候选搜索。不可只打乱事件行顺序。

健康或错误假设下没有可靠事件时，报告“有效事件数为零/相干指标未定义”，不能填 0 或 1。若合格背景控制不足，则 ΔS 也报告未定义，保留 RF 和覆盖率作为局部证据；不能挑选控制窗口直到获得较低背景分数。

图件固定为六张：

1. 0.5–1 s 原信号、D 和理论事件窗叠加，显示 A/B 分支及未检出事件。
2. 同一个事件类型/路径角组的三通道局部波形，校正前后共用坐标与事件集合。
3. 三通道 `tau(psi)`，开发拟合点与留出预测点分开画。
4. 事件序号 × 通道的 delta 热图，缺测留空，标注触碰边界的点。
5. 各方法的 TSA 和原时间轴包络阶次谱。
6. ΔS、覆盖率、到达误差与故障频率族保持的对比图；每个点为一个时间块，不能当独立重复样本。

固定比较：未对齐、全周期互相关、局部事件互相关、完整约束时移、去旋转对应约束、去路径平滑。若启用 beta，再加时移与时移+beta 的直接消融。局部互相关与新方法共用事件窗口、带宽、最大时移和开发/测试划分。

这里“全周期互相关”的周期明确为一个行星相对转动周期，标称约 0.185 s，包含 A/B 两个潜在接触事件，每周期只估一个时移；局部基线分别估每个事件的时移。它不是 15.5 s 的完整潮汐重复。若另外制作完整潮汐全局基线，须单独报告可用完整周期数，不能把两种周期定义混用。全周期和局部基线均用同路径角度组的开发模板，避免单一噪声周期作为参考。
