# 故障脉冲相位对齐：方法与评价方案

日期：2026-09-06。状态：研究方案与数学核查；新方法的实测效果尚未验证。

## 1. 建议确定的主线

**利用故障事件递归关系建立对应关系，在三通道中估计同一次事件的相对到达时延与振铃相位，再让同类事件在 TSA 中有效累加。**

建议方法名称：**故障事件约束的多通道时延—振铃相位对齐**。这是候选研究贡献，是否足以形成论文创新，要由相关方法的全文比较与公平实验证明。

各模块职责如下：

| 模块 | 本文中的职责 | 直接输出 |
|---|---|---|
| 振动驱动的粗角度估计 | 提供故障事件的粗时间坐标 | 公共运动相位估计及可信区间 |
| 运动学与潮汐递归 | 指定哪些冲击属于可比较的同类事件 | 事件编号、接触类型、行星架相对角度 |
| 本文对齐模块 | 校正事件时延与局部振铃相位 | 每个事件、每个通道的校正参数与拒绝标记 |
| SVD/TPSVD | 在相位校正后降噪，必要时在估计支路做保守预降噪 | 降噪后的事件矩阵与重构波形 |
| TSA | 累加已经对齐的同类故障响应 | 各通道 TSA，条件满足时再形成跨通道 TSA |
| 评价 | 判断增益是否与目标事件有关、能否在留出数据重复 | 相干增益、时延误差、覆盖率与故障特征保持 |

计算实现可以保留成熟的滤波、相关计算、最小二乘等工具。创新应落在**估计对象、可辨识约束、事件匹配和验证逻辑**上。

## 2. 为什么需要改动现有路线

本次直接检查了现有代码与输出：

1. `results/healthy_reference_feasibility_20260905/summary.csv` 中，PF50 的同一 2+3 通道组合：相位一致性由 0.473395 升到 0.881237，单事件频率族/背景由 19.508194 dB 降到 10.917071 dB，即下降 8.591124 dB。这支持改变优化目标，不能证明所有故障信息已经消失。
2. 工作区中的 `planetary-phase-alignment/src/kmopa_align.m` 当前以局部相关寻峰、相关可靠性、平滑插值产生相位映射。它适合作为已有原型/比较基线。
3. Shi 2025 的本地全文第 5 页、式 (5) 将 PCC 定义为 TSA 波形范数与周期间标准差范数之比；第 3.2 节用协方差匹配局部偏移。当前原型与它确有技术重叠。
4. 当前 v3 动力学代码存在事件真值和复路径接口，但这次没有获得其成功运行的验证记录，不能用这些接口的存在代替模型已验证。

### 两个必须修正的数学认识

对去均值、单位范数的事件波形 \(q_r\)，此前建议的

\[
C_{\mathrm{TSA}}=\frac{N\|\bar q\|^2-1}{N-1}
=\frac{2}{N(N-1)}\sum_{r<s}\langle q_r,q_s\rangle
\]

恰好等于**平均两两 Pearson 相关系数**。它有用，但改名并不产生新统计量。它可能为负；相互不相关时接近零只是一定噪声假设下的期望，不是任意信号的保证。

对任意相同支撑的波形，若标准差使用总体方差（分母为 N），普通 TSA 能量比例满足

\[
\frac{\|\bar x\|^2}{N^{-1}\sum_r\|x_r\|^2}
=\frac{\mathrm{PCC}^2}{1+\mathrm{PCC}^2}.
\]

若使用样本标准差，转换中的有限样本系数会改变，但仍是同一能量分解。因此“把 PCC 改写成能量保留率”不能单独作为创新。

此外，\(Y=[s;-s;s;-s]\) 的第一奇异值能量占比为 1，而 TSA 完全相消。**低秩不能保证有符号冲击同相**。建议保留低秩比作为降噪诊断量。

## 3. 先定义究竟对齐什么

一个事件应同时带有三个标签：

- 事件类型：太阳轮故障与某一行星轮啮合，或故障行星轮的太阳轮侧/齿圈侧接触。
- 递归编号：当前属于哪次同类型接触。
- 行星架相对角度：用于描述该次事件的传递路径状态。

同一行星故障齿与太阳轮、齿圈发生接触时，激励方向和波形可能不同，先分为两条事件序列。太阳轮故障依次与三个行星轮接触时，也保留接触行星的类别。不能直接将这些响应强制变成同一个模板。

没有机械零位时，初始相位是一个待估常量，事件编号是相对编号。周期递归能够约束相邻事件的间距，不能提供绝对“第 1 齿到达时刻”的真值。

### 当前参数下的递归检查

按当前代码 \(Z_s=21,Z_p=31,Z_r=84\)，太阳轮 600 rpm、齿圈固定：

\[
f_c=2\ \mathrm{Hz},\qquad f_m=168\ \mathrm{Hz}.
\]

单个故障行星轮的单侧接触重复率为 \(f_m/Z_p=5.41935\ \mathrm{Hz}\)；两侧接触合计事件率为 \(2f_m/Z_p=10.83871\ \mathrm{Hz}\)，但两类事件不因此变成相同波形。单个太阳故障齿与三个行星轮接触的合计事件率为 \(3f_m/Z_s=24\ \mathrm{Hz}\)。

同一故障行星齿且同一行星架位置的理想运动学重复需要

\[
L_c=\frac{Z_p}{\gcd(Z_p,Z_r)}=31
\]

圈行星架，即 15.5 s；60 s 只有约 3 个完整重复。**“一个潮汐周期固定包含 12 次冲击”不能从另一组仿真直接搬过来。** 其他论文对 tidal/hunting period 的定义可能不同，应明确本文选择的状态复现条件。

这些数值以代码中的 84 齿为条件；原始几何表的零变位近似与简单同心几何关系并不完全一致，应在建模参数审计中继续核实。此次方法方案不擅自改齿数。实测粗频率约 166.7 Hz 时，应随实测运动坐标生成事件，不能强制 168 Hz。

## 4. 方法优化：事件对应、时延与振铃相位联合约束

### 4.1 为什么单纯移动峰值不够

脉冲既有包络到达位置，也有包络内部的正负振铃。两段响应 \(s(u)\) 与 \(-s(u)\) 的包络峰值完全重合，但直接平均为零。

对每个事件，建议依次检查：

1. 是否找到了同一类接触事件，是否跨到了相邻事件；
2. 到达时间是否一致；
3. 到达对齐后，有符号振铃是否仍存在可重复的相位差。

### 4.2 有效事件模型与辨识边界

设 \(t_n^0\) 为粗运动坐标产生的事件时刻，\(\psi_n\) 为行星架相对角度：

\[
t_{j,n}^{\mathrm{obs}}=t_n^0+d_n+\tau_{j,c}(\psi_n)+\epsilon_{j,n}.
\]

\(d_n\) 是公共到达残差；\(\tau_{j,c}\) 是通道 j、事件类型 c 的有效相对时延。相减后

\[
t_{i,n}^{\mathrm{obs}}-t_{j,n}^{\mathrm{obs}}
=\tau_{i,c}(\psi_n)-\tau_{j,c}(\psi_n)+\epsilon_{i,n}-\epsilon_{j,n}.
\]

这一关系是三通道估计的基础。它消除了事件本身的共同发生时刻。

但 \(d_n\to d_n+g(\psi_n)\)、\(\tau_{j,c}\to\tau_{j,c}-g(\psi_n)\) 不改变观测。设 \(\sum_j\tau_{j,c}=0\) 可以固定计算参考，**不能证明 d 全部来自转速，更不能恢复绝对传递时间**。公共运动相位需单独用振动中的啮合轨迹估计，并用编码器独立评分；故障事件只能进一步约束可辨识的相对部分。

### 4.3 在事件频带中分开“时延斜率”与“振铃相位残差”

在单一故障事件占优、且频带内相位可近似为仿射函数的局部窗口中：

\[
Y_{j,n}(\omega)\approx A_{j,n}(\omega)S_n(\omega)
\exp\{-i\omega[d_n+\tau_{j,c}(\psi_n)]+i\beta_{j,c}(\psi_n)\}.
\]

其中 A 只表示幅值，不进行逆幅值补偿；\(\beta\) 描述带内额外相位，包括稳定的极性差。通道间单位互谱的相位满足

\[
\varphi_{ij,n}(\omega)
\approx-\omega\Delta\tau_{ij,c}(\psi_n)+\Delta\beta_{ij,c}(\psi_n).
\]

这里局部窗口的采样坐标是物理时间，ω 的单位为 rad/s，τ 为 s，β 为 rad；由角域定位窗口后仍可回取原始时间采样计算互谱。需要角度位移时再按当地角速度转换，不能把时延秒数直接当角度样本数。变速时结构振铃的角域宽度也可能变化，纯移位模型的适用性需要另外检验。

这是条件成立时的有效相位模型，不等于实测的绝对结构 FRF。至少需要两个有足够能量、频率间隔足够的频点区域，并结合事件搜索边界排除整周期歧义。只有一个窄谱线时，时延与常相位不可可靠分开。

若剩余相位明显非线性，说明该带存在色散、源混合或模型失配：应缩小有效频带/细分事件类型，或降低跨通道原始波形融合的适用范围。不能任意增加每事件相位自由度直到波形一致。

### 4.4 核心目标函数

先在固定频带上构造每个理论事件窗口的瞬态候选似然 \(L_{j,n}(t)\)：例如使用局部带内能量相对邻域背景的突出程度，保留多个候选峰及“本次未可靠检出”的状态。它表示候选证据，不能单独认定故障。

联合求解公共残差、路径场、相位场与事件指派：

\[
\begin{aligned}
J={}&-\sum_{j,n}w_{j,n}\log L_{j,n}(t_n^0+d_n+\tau_{j,c}(\psi_n))\\
&+\lambda_\varphi\sum_{i<j,n,\omega}w_{ij,n,\omega}
\{1-\cos[\varphi_{ij,n}(\omega)+\omega\Delta\tau_{ij,c}-\Delta\beta_{ij,c}]\}\\
&+\lambda_d\mathcal P_d(d)+\lambda_\tau\mathcal P_\tau(\tau)
+\lambda_\beta\mathcal P_\beta(\beta)+\lambda_{\mathrm{sym}}\mathcal P_{\mathrm{sym}}.
\end{aligned}
\]

其中各项先用开发数据的噪声/时间尺度无量纲化，再选择权重；拒绝事件使用预先固定的代价，避免所有窗口均被拒绝的平凡解。不能照搬 0.7/0.3 作为理论最佳权重。

约束包括：

- 位移小于局部最近异事件间距的一半，并留保护余量；事件指派保持顺序，不能跨到另一接触类型。
- 同一类型、同一路径的时延随行星架角度平滑。不同接触分支之间不强行连续。
- 相位平滑在单位圆上计算，避免 ±π 的表示跳变成为假物理突变。
- 公共残差受到独立粗运动坐标和光滑性约束，输出时称为“公共残余时移”；编码器未输入时不将它认定为真实转速误差。
- 允许拒绝低可信事件，记录拒绝数量、原因和覆盖率。

可采用交替求解：候选事件匹配 → 低阶路径场拟合 → 公共残差更新 → 检查目标与约束。相位场由多个事件共同拟合，不为每个事件、每个频点自由设相位。无需引入机器学习分类器。

单独的互谱时延估计、圆回归和周期平滑都是已有工具。候选区别在于它们受**接触事件分支、运动学递归、跨通道路径一致性和适用性检验**共同约束；必须用消融验证这些约束的实际价值。

### 4.5 三个 120° 测点如何真正参与

取 \(\alpha_j=0,2\pi/3,4\pi/3\)，可把相对时延写成

\[
\tau_{j,c}(\psi)=b_{j,c}+
h_c(\psi-\alpha_j)-\frac13\sum_{r=1}^3h_c(\psi-\alpha_r)+u_{j,c}(\psi),
\]

并令 \(\sum_j b_{j,c}=\sum_j u_{j,c}=0\)。h 是低阶周期函数，u 是受惩罚的通道特有偏离。相位场可采用相应的圆周参数化。

这个模型使用的是**旋转对应关系的软约束**。单个故障行星轮打破三源完全等价，外壳和安装也可能不对称，因而不强制所有场只含 3k 阶。

事实上 \(\cos[3(\psi-\alpha_j)]=\cos(3\psi)\)，3k 阶共同路径项在上述去通道均值后恰好消失。它们属于相对观测的盲区。三个测点在单一角度上的空间采样还存在模 3 混叠；跨角度轨迹能够增加信息，但不能消除所有公共项的规范自由度。

### 4.6 补偿和 TSA 的接口

对补偿所用的局部解析带通信号，以一致的 Fourier 符号约定施加

\[
\widetilde Y_{j,n}(\omega)=Y_{j,n}(\omega)
\exp\{+i\omega\widehat\delta_{j,n}-i\widehat\beta_{j,c}(\psi_n)\}.
\]

\(\widehat\delta\) 包含当前可支持的事件位移。校正到同一事件角度下的通道参考/虚拟平均参考；所有通道共有的路径相位仍保留。同类事件、相近路径位置之间做 TSA，不能跨所有角度强求完全相同的波形。

实现要求：

1. 估计支路可以归一化；输出保留原始幅值尺度。
2. 补偿在有 padding 的局部解析频带进行；回到实信号时负频率满足共轭对称，不能对实 FFT 两侧同时乘同一个任意复常数。
3. 单位模相位算子在完整频带/完整支撑上保持谱幅值与能量，但裁切、滤波、加窗和非线性重采样会改变测得能量。须单独量化这些损失，不能声称整个流程严格幅值不变。
4. 首版输出事件张量 `[时间块, 事件类型, 路径角度组, 通道, 局部采样点]` 与局部 TSA。若重建整周期，使用明确的过渡窗/重叠相加，并审查边界伪影。
5. 用事件控制点插值位移时，PCHIP 本身不保证 \(1+\delta'(\theta)>0\)。需要显式检查采样映射单调性和最大变形。
6. 对齐参数与频带冻结后，TPSVD 使用同一秩选择规则；主相位评价先在最终 SVD 之前计算，避免低秩重构把评分波形先做得更相似。

## 5. 建议主评价：事件特异性相干增益

一个实测指标不能单独证明“对齐的一定是真实故障”。建议主指标与位移真值、覆盖率、健康对照共同构成证据。这里提供可直接实现的定义。

### 5.1 跨时间块的有符号相干比例

先固定事件类型、通道和可比较的路径角度组。从至少两个留出时间块中取相同长度、去均值、统一加窗的**有符号带通波形** \(w_{b,r}\)。块内数量为 \(N_b\)。相位评分的副本定义为

\[
q_{b,r}=\frac{w_{b,r}}{\|w_{b,r}\|_2},\qquad
\mu_b=\frac1{N_b}\sum_r q_{b,r}.
\]

这里仅消除每个窗口的正幅值尺度，保留正负极性；未达到预设有效能量门槛的窗口标记未检出，不能把噪声任意归一化后充作故障事件。最终输出信号仍保留原幅值。

\[
R_\phi=
\frac{2}{B(B-1)}\sum_{b<c}\operatorname{Re}\langle\mu_b,\mu_c\rangle,
\]

Rφ 衡量不同留出块中的平均响应是否保留共同的有符号结构。同形、同相的响应即使正幅值不同，也得 1；独立零均值且方向对称的噪声在固定处理下，其跨块项期望为 0；反相时可以为负。不得取绝对值或把负值裁成零。少于两个有效块时返回未定义。

再以原幅值波形的块均值 \(\bar w_b\) 计算辅助量

\[
R_E=\frac{\frac{2}{B(B-1)}\sum_{b<c}\operatorname{Re}\langle\bar w_b,\bar w_c\rangle}
{\frac1B\sum_b\frac1{N_b}\sum_r\|w_{b,r}\|^2}.
\]

RE 用于检查实际 TSA 能量保持。它在幅值差异很大时，即使相位一致也可能小于 1，因此不能把 RE 的所有变化都解释成相位变化。零分母时返回未定义。常量传感器增益会从两个比例中消去，但它不能恢复真实物理加速度。

这里“独立噪声”是解释期望值所需的假设，不是实测自动满足的事实。相邻时间窗也不等于独立重复试验。

与同一批窗口的 PCC 相比，跨块内积避免把同块噪声自能量直接当相干能量。Rφ 本身等于跨块的归一化波形内积平均，仍属于相关统计。提出的评价增量在于下面的事件特异性对照和独立预测协议，不能声称 Rφ 是全新数学工具。

### 5.2 用对照检查事件特异性

对目标事件得到 \(R_F=R_{\phi,F}\)，对预先规定、数量/长度/搜索自由度相配的背景或错误事件假设得到 \(R_{B,k}=R_{\phi,B,k}\)。定义

\[
S=R_F-\frac1K\sum_{k=1}^K R_{B,k},
\qquad
\boxed{\Delta S=S_{\mathrm{aligned}}-S_{\mathrm{unaligned}}}.
\]

建议名称：**事件特异性相干增益**，作为评价方案的主数值。

若普通啮合背景在目标窗口和控制窗口里都重复，单独 Rφ 可以很高，而 S 不因此得到同样的提高。若故障同类事件的相干结构在处理后增强、控制没有同步增强，ΔS 才支持事件特异性的改进。不同通道/事件类型/角度组按预先固定的权重汇总，报告各组原始值；不能按测试得分重加权。RE 同时报告，用于识别评分副本的相干改善是否转化成原幅值 TSA 的收益。

控制组的设计比改写公式更重要：

- 同记录的非事件位置：排除两条故障接触分支，尽量匹配角度覆盖与啮合背景；若无法匹配，则注明混杂，不能把差值当成特异性证明。
- 错误周期假设：选定合理偏离真实递归且不落在已知故障分支/谐波上的假设，用同等校准与搜索过程处理。仅给所有事件加同一常数，会被未知初相位吸收，不是有效错周期检验。
- 健康 BL：按同样故障假设处理，检查是否也得到大幅“对齐收益”。健康与故障之间不用未校准的绝对振动幅值作证据。

仅随机重排事件窗口的行顺序不会改变 TSA，因而不能作为破坏相位的负对照。随机时间扰动应超出算法的允许恢复范围，并控制窗口覆盖变化；该人工对照也不能替代健康记录。

### 5.3 防止算法给自己打分

独立时间块本身不足以避免自我评分：如果每个测试窗口又为最大化相似度单独寻移位，独立噪声也可能被拟合成共同形状。

首轮冻结频带、事件规则、路径复杂度、最大位移、SVD 规则及拒绝阈值。每条记录只用早期开发段估计模型和一个初始角偏置，后续块评价。对要评价的 S3 事件，可用 S1/S2 的当次观测加已冻结的 S3 路径模型预测校正，S3 当次波形只评分；再轮换被留出的通道。三通道完全参与的最终算法另报告全部输出。预测失败本身是模型适用性证据。

负对照也经过相同的自适应处理流程。用于最终评分的窗口、归一化分母、极性规则均不能按测试结果修改。评分不再额外做一次最佳移位、翻转极性或 DTW。

### 5.4 必须随主指标报告的四项量

| 量 | 作用 | 解释边界 |
|---|---|---|
| 已知注入时延/相位的误差 | 判断校正参数是否准确 | 仅控制试验/已知模型有真值；只消除预先规定的参考常量 |
| 留出事件到达时间离散度 | 判断事件间距是否更稳定 | 不能证明振铃同相或故障身份；未知零位时不评绝对齿号位置 |
| 事件覆盖率及拒绝分布 | 检查是否仅保留少量容易事件 | 分母为分析区间全部理论候选事件；同时给相同覆盖率对比 |
| 故障频率族/背景、单通道结果 | 判断特征保持及融合收益 | 不是物理 SNR，不是分类准确率，不能要求任何记录中均超过健康 |

计算角度误差时，若用故障周期归一化，应明确 \(\Delta\phi=2\pi\Delta t/T_f\)；若用行星架角度，则使用 \(\Delta\psi=\omega_c\Delta t\)。两者不能混作同一种“度”。
