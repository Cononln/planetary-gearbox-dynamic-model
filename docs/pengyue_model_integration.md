# 彭悦（2025）建模框架的融合实现

本项目没有将现有 18+7 自由度模型替换为论文中的刚性 18 自由度模型。
论文中对本研究最有价值的部分，是固定传感器坐标下的移动啮合源投影。
当前实现采用如下分层形式：

1. 18 自由度太阳轮、齿圈、行星架和三行星平移—扭转模型；
2. 7 个齿圈弹性模态，直接与内啮合力双向耦合；
3. 固定传感器的安装位置角与敏感方向角；
4. 随行星架角变化的移动源几何及复数传递函数；
5. 可选线性、单边和齿侧间隙接触模型。

## 固定传感器坐标

`pg_sensor_configuration` 分别保存传感器圆周安装位置和敏感轴方向。
`pg_sensor_observation` 将齿圈刚体及径向模态加速度投影到敏感轴。
`pg_fixed_path_kinematics` 给出每个行星轮啮合点相对于固定传感器的
径向和切向投影。由于系统自由度已经定义在惯性坐标系中，传感器观测
矩阵本身保持固定，时变性进入啮合向量、系统矩阵和移动源输入向量；
这与先在行星架坐标建模、再变换到固定坐标在物理上等价。

`pg_path_frf` 和 `pg_path_field` 输出

    H_jp(f,phi_c) = -(2*pi*f)^2 C_j D(f,phi_c)^(-1) g_p(phi_c),

从而同时保留几何投影、齿圈模态幅值变化和结构传播相位。

## 接触非线性

`p.contact.model` 的默认值为 `linear`，以保持现有论文结果可复现。
可选值为：

- `unilateral`：只承受压缩，用于脱啮/再冲击敏感性分析；
- `backlash`：带对称死区的双齿面接触；
- `linear`：原模型。

非线性算例必须使用 `pg_simulate_nonlinear_contact_response`。该函数采用
隐式 Newmark 法并在每个采样点使用活动接触切线进行 Newton 迭代。
现有线性求解器会拒绝非线性配置，避免只在输出阶段截断啮合力而没有
真正反馈到动力学方程。

齿面摩擦参数保留为关闭状态。只有在摩擦系数及润滑工况得到标定后，
才应把切向摩擦力加入主结果。

## 故障模型

25% 和 50% 断齿继续采用齿宽条带积分；这与实际缺失接触面积一致。
裂纹势能模型保留为独立机理算例，不能用论文中模数 5 mm 齿轮的
3 mm 裂纹深度直接替代本试验的断齿尺寸。
