# 故障脉冲到达对齐 V2

目的：以故障候选事件的到达时刻为对齐目标，比较局部包络互相关和周期/空间约束候选匹配。

## 当前结果

首轮输出：`results/event_arrival_v2_20260906_072759`。包络事件集中程度较 V1 提高，但联合约束相对于局部包络互相关尚无稳定总体优势。详细判断与各指标的独立性边界见该目录的 `故障脉冲到达对齐_V2报告.md`。

原始数据和 V1 输出未修改。本轮沿用此前已查看的数据及预处理，不宣称新盲测。

## 执行

在项目目录中，用匹配项目二进制包的 Python 3.12 运行（NumPy/SciPy/Matplotlib/Pillow 在 `runtime/phase_python`）。下面的 `python` 表示该解释器。

```powershell
python -u tests/test_event_arrival_v2.py
python -u scripts/run_event_arrival_v2.py --run
```

主程序创建新的时间戳目录。对所输出目录运行：

```powershell
python -u scripts/plot_event_arrival_v2.py results/event_arrival_v2_20260906_072759
python -u scripts/audit_event_arrival_v2.py results/event_arrival_v2_20260906_072759
```

绘图命令重建派生图表和报告，不重新拟合算法；绘图后应重新目视检查。主程序支持 `--source` 指定兼容的 V1 缓存，默认使用已完成的首轮 V1 目录。

## 模块

- `src_py/event_arrival.py`：包络、固定上升沿标记、模板、候选时差、相对路径、联合序列候选选择与留出预测。
- `scripts/run_event_arrival_v2.py`：先开发选型、后冻结测试，包含健康及错误阶次控制。
- `tests/test_event_arrival_v2.py`：已知时刻随机振铃相位控制、留出通道隔离、冻结和零证据检查。
- `scripts/plot_event_arrival_v2.py`：三组科研图和中文报告。
- `scripts/audit_event_arrival_v2.py`：代码散列、时移边界、时间映射、数值及导出文件检查。

本版本未把 SVD 的降噪收益混入事件对齐评分，也未做幅值逆补偿。原波形频谱为连续时间块上的重构结果，而非短事件窗串接。
