# 故障事件约束时移：代码运行说明

## 当前结果

首轮已运行 BL/PF50 三通道真实振动，输出在 `results/event_alignment_v1_20260906_053745`。约束时移改善 PF50 候选到达预测与包络一致性，未改善有符号波形相干性；当前不支持宣称相位对齐成功。详细数值、适用边界和下一版进入条件见该目录的 `真实数据实现报告.md`。

源数据、原 MATLAB 程序和此前结果均保留。方案配置未改成自动运行，实际结果目录单独保存执行配置和代码散列。齿数几何一致性待核实，本轮暂沿用已有代码参数。

## 运行环境

Python 3.12，NumPy、SciPy、Matplotlib。脚本将项目的 `runtime/phase_python` 添加到模块搜索路径；本轮已用匹配的 Python 3.12 运行。不要将这一套 cp312 二进制包直接交给 Python 3.14。

## 入口与复现

在项目目录中，用匹配的 Python 解释器执行下列命令。`python` 指上述解释器，不是任意版本的系统别名。

```powershell
# 数值单元测试：不读取真实数据。
python -u tests/test_event_alignment_python.py

# 完整重跑：读取方案中的 BL/PF50，创建新的时间戳结果目录。
python -u scripts/run_fault_event_alignment.py --run --stage complete

# 对首轮结果作包络/有符号波形诊断：不重新拟合、不选择新参数。
python -u scripts/diagnose_fault_event_alignment.py results/event_alignment_v1_20260906_053745

# 由该目录已保存的数值输出生成报告和七组 Python 图。
python -u scripts/plot_fault_event_alignment.py results/event_alignment_v1_20260906_053745
```

最后两条会重新生成指定目录下的派生诊断/图表/报告，不改变原信号、冻结模型及主试验数值。绘图重跑后需要重新目视复核，QA 状态重置为待复核是有意设计。

## 实现模块

- `src_py/event_alignment.py`：读取、振动运动相位、候选事件、空间约束时移、插值、SVD 与评价。
- `scripts/run_fault_event_alignment.py`：开发选择、冻结后评估、健康及错误阶次控制、留一通道预测。
- `scripts/diagnose_fault_event_alignment.py`：同事件掩码的包络/有符号波形诊断，并验证有符号评分与主试验一致。
- `scripts/plot_fault_event_alignment.py`：图表、可编辑矢量输出、数值报告及初步 QA。
- `tests/test_event_alignment_python.py`：已知候选时刻恢复、留出隔离、模型冻结、零证据拒绝、插值与原时间轴重构。

单元测试通过不等于真实故障波形已经对齐。对比图中的幅值采用采集单位；未知灵敏度未被转换成绝对加速度。跨事件评分用归一化副本，未做传递路径幅值逆补偿。
