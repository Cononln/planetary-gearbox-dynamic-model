# 真实50%太阳轮断齿诊断结果

相位解耦参数在诊断前已经冻结。诊断比较三种输入：0°单测点、未对齐双通道等权融合、
相位对齐后的双通道等权融合。所有方法使用相同的1、4、11、13倍啮合频带和相同幅值
标度，因此差异来自通道融合及相位校正。

编码器事后给出的太阳轮故障频率为23.828 Hz，无编码器振动估计为23.821 Hz。包络频谱中
可见1–4倍故障频率族。

| 指标 | 0°单测点 | 未对齐融合 | 相位对齐融合 |
|---|---:|---:|---:|
| 1倍故障幅值 | 0.1620 | 0.0897 | 0.1249 |
| 2倍故障幅值 | 0.0640 | 0.0466 | 0.0727 |
| 3倍故障幅值 | 0.0508 | 0.0234 | 0.0546 |
| 故障族相对未对齐增益 | 4.89 dB | 0 dB | 3.48 dB |
| TPSVD前三阶能量占比 | 0.882 | 0.864 | 0.884 |
| 行星架周期复现性 | 0.697 | 0.704 | 0.707 |

相位对齐恢复了未对齐融合中的相消，并提高了2、3倍故障线和TPSVD能量集中度，但等权融合
仍未超过最佳单测点。下一步应在不改变相位模型的前提下，根据各谐波的背景噪声或相位
可靠度学习通道权重。由于目前只有一个50%断齿文件，这些结果表示特征可见性，不能解释为
分类准确率或跨工况泛化结果。
