# 当前模型与算法状态

此文件是多 AI 接手入口；历史文档中的计划、早期模型与初步结论不能直接视为
当前方法已验证的结论。

## 1. 当前动力学模型

三行星，太阳轮输入、齿圈固定、行星架输出。18 个齿轮系统集中参数自由度，
另加 7 个有效齿圈弹性坐标。`paper_v3` 主入口的传感器位于 0°/120°/240°，
暂按径向向外；独立 ANSYS 后处理资产可包含 0°/90°/120°/240° 四个测点，
不能把两套测点配置混称为同一响应。

| 功能 | 入口 |
| --- | --- |
| 基础几何、质量、惯量 | `src/pg_parameters.m` |
| 载荷与有效模态先验 | `src/pg_parameters_loaded_v2.m` |
| 当前三通道配置 | `src/pg_parameters_paper_v3.m` |
| 耦合矩阵 | `src/pg_coupled_matrices.m` |
| 固定测点与移动啮合点 | `src/pg_fixed_path_kinematics.m`、`src/pg_sensor_observation.m` |
| 复传递函数 | `src/pg_path_frf.m` |
| 断齿时变刚度 | `src/pg_tvms.m` |
| 线性有载响应 | `src/pg_simulate_loaded_v2_response.m` |
| 可选非线性接触响应 | `src/pg_simulate_nonlinear_contact_response.m` |
| 三通道生成入口 | `scripts/simulate_paper_v3_three_channel_response.m` |

`pg_path_frf` 用冻结行星架角度下的同一组耦合矩阵计算加速度频响：
`H = -omega^2 * Cacc * (K - omega^2*M + 1i*omega*C)^(-1) * g`。
运动轨迹、TVMS、传递误差和故障时刻由一致的运动相位驱动。

默认输入 20 N m、理想平衡输出负载 100 N m。断齿 25%/50% 对应缺失齿宽比例，
缺失部分至齿根圆；根裂纹是独立的可选机制。响应默认采样率 51200 Hz、
有效时长 3 s、丢弃瞬态 0.2 s。

### 物理证据边界

- 仅有 30 阶固有频率，没有对应 FE 振型、有效模态质量或实测锤击 FRF。
  当前振型、阻尼与模态质量为有效模型假设，绝对幅相未经实验标定。
- 第 15 阶作为轴对称模态及其质量缩放是待验证假设。
- 齿数暂沿用 21/31/84；标准同模数关系应给出齿圈 83 齿，几何仍待核对。
  因此 168 Hz 啮合频率等数值与当前配置绑定。
- 啮合传递误差、支承和部分阻尼为工程估计，不应为了目标频谱外观随意调整。
- `validate_paper_v3_model` 是运动、事件与路径周期性的数值机制检查，
  不是模型已经通过实验标定的证明。

## 2. 当前太阳轮对齐试验

入口：`scripts/test_sun_signed_waveform.py`。

三通道振动 → 振动估计运动相位 → 带符号 4–10 kHz 波形 →
比较未对齐 / 整段 Pearson 时移 / 逐潮汐 Pearson 时移 →
太阳轮潮汐矩阵 → 直接 TSA 或固定秩 SVD 后 TSA → 三通道带符号均值 → FFT。

这里估计的是 S2、S3 相对 S1 的时移；尚未增加矩阵行间或逐个故障事件的独立
对齐步骤。相同太阳轮潮汐长度为 1 个行星架转周期，当前配置包含 84 次啮合、
12 次太阳轮故障事件。行星轮完整潮汐为 31 个行星架转周期。

匹配、TSA 与融合保留波形正负号；固定秩 0/1/2 分别用于直接平均与低秩试验。
这些固定秩结果不等于原稿 PSI 加权选模态。历史包络方法保留在其他入口中。

### 最近本地太阳轮记录（探索性结果）

结果目录标识：`sun_signed_waveform_20260906_221857`，未随仓库上传。

形成 111 行 × 16384 点/通道，周期约 0.50448 s。

| --- | ---: | ---: | ---: |

估计平均啮合频率与编码器事后结果接近，只支持平均转速一致性，不证明瞬时相位准确。

## 6. 独立的 ANSYS 齿圈模态传递路径

新增路径不改变 18DOF 源动力学矩阵，而是用三路 PR 啮合力单向激励
ANSYS 导出的齿圈/箱体模态，再由导出的测点径向振型恢复响应。
当前四测点本地标签为 0/90/120/240 度；角距离与移动接触位置必须
使用资产中的 FE 全局角度。本地标签按顺时针，FE 全局角按逆时针；
三/四测点 CSV 构建器逐标签检查实际节点中心，避免 120°/240°互换。
核心文件位于 src/pg_fe_ring_*.m 和
src/pg_apply_fe_ring_transfer_causal.m；入口及本地资产准备见
[独立 FE 路径说明](fe_ring_modal_transfer_path.md)。

该路线已有本地 60 阶模态的模拟诊断，但 ANSYS 原始文件、压缩 MAT 资产、
结果 CSV 和图片不随仓库上传。0.02 模态阻尼为暂定值，绝对幅相未经
实验 FRF 标定；N-mm-MPa 模态振型转 SI 后的质量归一化仍需广义质量核验，
因此当前路径幅值暂不作 m/s² 定量结论。事件窗内最大振铃峰时刻不等于波前首次到达时间。
旧 18+7 有效模态路线的证据边界仍按第 1 节解释，不能混作这一路线的结果。

## 7. FE 传递路径坐标重注册（2026-09-28）

根据当前装配约定，`SENSOR_0` 为齿圈上方，1 号行星轮在源模型局部
`0°` 时位于其正下方；源模型局部角顺时针为正，而 ANSYS 全局角
`atan2` 逆时针为正。因此移动载荷的 FE 接触角采用

    theta_FE = [sensor0_global - (phi_c + planet_phase_i)]_(2*pi)

实现位置为 `src/pg_fe_ring_contact_angle.m`，对应函数的全局测点角来自
模态资产，而不是把本地标签直接当作 FE 角度。若 `phi_c=0`，P1/P2/P3
在 `SENSOR_0` 全局角约 90° 时分别为 90°、330°、210°。这是一套明确的
坐标注册约定；绝对装配零位仍应与试验或 FE 建模记录核对。

已用保存的 18DOF 健康和 `q_c=0.90 mm`、45° 太阳轮裂纹源响应，以及四测点
ANSYS 模态资产重新计算 2 s 因果路径，结果位于
`results/fe_causal_q090_corrected_registration_20260928/`。复算脚本为
`scripts/remap_saved_fe_path_q090.py`，不会重算或修改 18DOF、TVMS、啮合阻尼、
ANSYS 模态和源 MAT/CSV。

旧注册 `theta_FE=phi_c+planet_phase_i` 仅用于回归校验；在 `t>=0.0200043 s`
的健康/故障八路信号上，复算与历史 MATLAB 因果 CSV 的最大相对 L2 误差为
`1.1191e-12`，因此修正后的差异来自坐标映射，而不是数值积分差异。源记录
采样率为 131072 Hz，保存时间为 2 s，模态阻尼比为 0.02；源记录本身已在
18DOF 仿真的 0.2 s 过渡段之后保存。

对 48 个源故障事件的逐事件表见
`corrected_event_metrics.csv`。修正注册下，四个局部测点对应的 FE 全局角约为
`0°→90°`、`90°→360°`、`120°→330.04°`、`240°→210.02°`。故障增量 RMS
（m/s²）依次为 `4.6855e-5`、`7.4021e-5`、`2.9286e-5`、`3.5413e-5`。
这里的接触点特指发生太阳轮 SP 裂纹啮合的行星轮在齿圈上的 PR 接触位置。
在四个重复几何状态中，该接触点最近的测点与事件峰值最强一致了 24/48 个事件：
状态 3（接近 90°）由 90°测点最强，状态 4（接近 0°）由 0°测点最强；状态
1/2 中 90°测点仍强于角距离更近的 240°测点。因此当前 FE 模态路径支持“局部
接触附近可能形成热点”，但不支持“角距离越近必然越强”或“距离越远必然越晚”。

更重要的是，单个太阳轮裂纹 SP 事件会经 18DOF 耦合改变全部三路 PR 力，
而不只是对应行星轮一路。`source_pr_force_event_metrics.csv` 给出逐事件证据：
首事件的 active P2 在同一事件窗内故障增量 RMS 为 2.58 N，P1/P3 分别为
1.38/1.29 N。active P2 较强，但另两处移动 PR 入射点也贡献传递路径响应。
因此上述 24/48 是“active 行星轮接触角与测点峰值”的相关性统计，不能据此
把完整四测点波形归因于单一 PR 施力点；对多源贡献的因果分解需另作诊断。

新逐事件表使用 `[event_start−4 ms, event_end+4 ms]` 窗，与当前源码一致；
历史旧角事件 CSV 使用的时间参考/窗口与之不同，旧、新事件表的峰值和滞后
不可逐行直接比较。上述数值等价校验针对的是保存的时域波形，且只在保留记录
的前 20 ms 模态初始瞬态之后成立。

该路径没有显式波速传播项或按角距离施加的经验延迟/衰减；测点差异来自移动载荷
投影到各阶模态后的振型乘积、共振/反共振和多模态干涉。`peak_lag_s` 是事件窗内
最大振铃峰相对源事件起点的位置，不是材料波首达时间。因此目前可以报告相对测点
响应和坐标注册证据，但不能把这些峰值延迟解释为严格的路径传播时间；绝对幅值仍受
ANSYS 模态 SI 质量归一化和实验 FRF 标定边界约束。

## 9. 章节路线与几何标注确认（2026-09-30）

用户已确认第三章和第四章采用两条不同路线，不能在同一张图或同一段结论中
混用：

- 第三章动力学响应使用旧的 18DOF + 7 个有效齿圈模态坐标双向耦合路线；
- 第四章传递路径使用 18DOF 三路 PR 力驱动 ANSYS 齿圈/外部结构模态的单向路线。

本轮不生成传递路径示意图。FE 资产的 `SENSOR_0` 正方向采用全局 `+y`，
局部 0°从该方向起按顺时针增加；在当前装配约定下，P1 的行星轮中心和其
对应 PR 接触点均按 SENSOR_0 正下方理解。图面若需要表达齿圈几何，齿圈半径
只标解析名义值 63.000 mm；数值 FE 传递仍使用模态网格实际接触半径。压力角
只标名义值 20°，不把代码反算的 SP 工作压力角写成图面参数。
上述方向约定用于第四章 FE 测点注册和章节标注；本次没有回写第三章源模型的
`planetPhase0` 或旋转已保存的源记录，已有数值结果仍以记录中的
`carrierAngleRad` 为准。

按彭悦第四章式(4-1)～(4-10)，(U,V) 是把构件平移量旋转、平移到以固定
传感器为原点的坐标系后的两个笛卡尔分量；它们本身不是啮合线法向/切向量。
啮合线投影是在式(4-5)、(4-8)中用啮合角对 (U,V) 的差分再次投影得到的。
当前第三章的载体固定18DOF实现和第四章的FE单向路径均没有把这组变量作为
同名输出，因此本项目不把现有结果冒充为彭悦式 (U,V) 响应，也不据此声称
已经证明“坐标变换产生调制”。
