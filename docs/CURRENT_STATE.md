# 当前模型与算法状态

此文件是多 AI 接手入口；历史文档中的计划、早期模型与初步结论不能直接视为
当前方法已验证的结论。

## 1. 当前动力学模型

三行星，太阳轮输入、齿圈固定、行星架输出。18 个齿轮系统集中参数自由度，
另加 7 个有效齿圈弹性坐标。当前传感器位于 0°/120°/240°，暂按径向向外。

| 功能 | 入口 |
| --- | --- |
| 基础几何、质量、惯量 | `src/pg_parameters.m` |
| 载荷与有效模态先验 | `src/pg_parameters_loaded_v2.m` |
| 当前三通道配置 | `src/pg_parameters_paper_v3.m` |
| 耦合矩阵 | `src/pg_coupled_matrices.m` |
| 固定测点与移动啮合点 | `src/pg_fixed_path_kinematics.m`、`src/pg_sensor_observation.m` |
| 复传递函数 | `src/pg_path_frf.m` |
| 断齿时变刚度 | `src/pg_tvms.m` |
| 线性有载响应 | `src/pg_simulate_loaded_v2_response.m` |
| 可选非线性接触响应 | `src/pg_simulate_nonlinear_contact_response.m` |
| 三通道生成入口 | `scripts/simulate_paper_v3_three_channel_response.m` |

`pg_path_frf` 用冻结行星架角度下的同一组耦合矩阵计算加速度频响：
`H = -omega^2 * Cacc * (K - omega^2*M + 1i*omega*C)^(-1) * g`。
运动轨迹、TVMS、传递误差和故障时刻由一致的运动相位驱动。

默认输入 20 N m、理想平衡输出负载 100 N m。断齿 25%/50% 对应缺失齿宽比例，
缺失部分至齿根圆；根裂纹是独立的可选机制。响应默认采样率 51200 Hz、
有效时长 3 s、丢弃瞬态 0.2 s。

### 物理证据边界

- 仅有 30 阶固有频率，没有对应 FE 振型、有效模态质量或实测锤击 FRF。
  当前振型、阻尼与模态质量为有效模型假设，绝对幅相未经实验标定。
- 第 15 阶作为轴对称模态及其质量缩放是待验证假设。
- 齿数 `21/31/84` 中的齿圈 `Zr=84` 已由用户实物数齿确认。零中心距修正时
  `Zs+2Zp=83` 只是特例；84 齿可以通过中心距/齿形修正闭合，但不能把代码中的
  中心距修改直接等同于已知制造变位。太阳轮与 31 齿行星轮图纸均明确 `x=0`，
  当前模型按用户指定使用名义中心距 `39.75 mm`；齿圈实物齿形与两张外齿图纸
  尚须在总装中实测核对。168 Hz 等数值仍与当前配置绑定。
- 两个啮合副的有效齿宽均为用户确认的 `21.5 mm`；此前参数源中的 `22/42 mm`
  已更正。2026-09-08 新增齿圈外圆半径 `81.0 mm`、内齿根圆半径 `64.875 mm`、
  八个贯穿 `Ø6.8 mm` 安装孔（孔心半径 `72.5 mm`），齿圈外轮缘与箱体一体。
  健康 PR-TVMS 的 Python 势能法现以含孔等厚环形轮缘平面应力 FEM 替代旧的内齿根
  截面延拓基础项；细网格得到 `C_f,ring=3.937e-10 m/N`（`k_f,ring=2.540e9 N/m`），
  相邻粗网格差异 `1.412%`。该结果仍是二维工程近似：齿根过渡圆角、完整三维箱体
  与局部安装边界尚未识别，不能作为经实验标定的绝对刚度。
- 材料暂按用户指定的通用结构钢：`E=200 GPa`、`ν=0.30`、`ρ=7850 kg/m³`；
  这是一阶工程先验，不等同于材料牌号或热处理后的实测常数。
- 2026-09-07 用户提供的太阳轮与 31 齿行星轮参数表确认：`mn=1.5 mm`、
  `α=20°`、`h_a*=1`、`β=0`、`x_s=x_p=0`；跨齿公法线分别为
  `W_3=11.512 mm`、`W_4=16.150 mm`。两表中“配对齿轮 34 齿”及其配对中心距
  已由用户确认是填写错误，不能用于拓扑、中心距或啮合频率推导；实际研究对象
  仍为 `21/31/84` 单级三行星结构。
- 同日对用户提供的原生模型归档 `ZLS160-5-S-T.zip` 的只读盘点，确认其中有
  `太阳轮齿轮-圆柱齿轮21×1.5.SLDPRT`、`行星轮-圆柱齿轮31×1.5.SLDPRT`、
  `齿圈M1.5X84.SLDPRT`、太阳轮/行星轮子装配及顶层总装，且归档中不存在
  34 齿零件。该证据支持 21/31/84 的构件身份，但原生 SLDASM 的压缩引用表尚未
  被离线读取，不能仅凭文件名断言实际中心距或配合关系。
- 啮合传递误差、支承和部分阻尼为工程估计，不应为了目标频谱外观随意调整。
- `validate_paper_v3_model` 是运动、事件与路径周期性的数值机制检查，
  不是模型已经通过实验标定的证明。

## 2. 当前太阳轮对齐试验

入口：`scripts/test_sun_signed_waveform.py`。

三通道振动 → 振动估计运动相位 → 带符号 4–10 kHz 波形 →
比较未对齐 / 整段 Pearson 时移 / 逐潮汐 Pearson 时移 →
太阳轮潮汐矩阵 → 直接 TSA 或固定秩 SVD 后 TSA → 三通道带符号均值 → FFT。

这里估计的是 S2、S3 相对 S1 的时移；尚未增加矩阵行间或逐个故障事件的独立
对齐步骤。相同太阳轮潮汐长度为 1 个行星架转周期，当前配置包含 84 次啮合、
12 次太阳轮故障事件。行星轮完整潮汐为 31 个行星架转周期。

匹配、TSA 与融合保留波形正负号；固定秩 0/1/2 分别用于直接平均与低秩试验。
这些固定秩结果不等于原稿 PSI 加权选模态。历史包络方法保留在其他入口中。

### 最近本地太阳轮记录（探索性结果）

结果目录标识：`sun_signed_waveform_20260906_221857`，未随仓库上传。
沿用数据采样率 51200 Hz，截取第 30–90 s；完整分析支持约 33–88.9975 s，
形成 111 行 × 16384 点/通道，周期约 0.50448 s。

| 直接 TSA 指标 | 未对齐 | 整段对齐 | 逐潮汐对齐 |
| --- | ---: | ---: | ---: |
| 通道相干能量比例 | 0.3333 | 0.4114 | 0.3868 |
| 高频故障间隔梳状谱/背景（dB） | 0.114 | 0.517 | 0.373 |
| 奇偶行融合 TSA 相关系数 | 0.0484 | 0.0266 | 0.0382 |

以上摘要来自既有本地试验，仓库整理未重跑。梳状谱指标不是物理 SNR，也不是
真实故障接触时刻标签。整段结果有部分指标增益，但跨行重复性仍低；现有证据
尚不能证明稳健的故障脉冲对齐或所提联合方法优于互相关。固定秩 SVD 收益有限。
估计平均啮合频率与编码器事后结果接近，只支持平均转速一致性，不证明瞬时相位准确。

## 3. 后续工作应解决的问题

优先明确故障源事件、测点到达与振铃相位的验证对象；在统一周期长度、数据
支持、SVD/TSA 后端和留出数据上比较。核对几何、测量极性、灵敏度与采样率。
对方法有效性的进一步结论需要新的受控验证，而不是只看对齐目标自身的分数。

上传和环境自检不触发完整研究实验。其他 AI 开始任务时，应先由用户指定此次
要处理的具体问题。
