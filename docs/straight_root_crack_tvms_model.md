# 直线齿根裂纹 TVMS 模型

## 适用范围

本模型用于当前单级行星齿轮箱的太阳轮单齿裂纹与行星轮单齿裂纹。
它只计算故障时变啮合刚度，不计算动力学响应。健康几何、工作中心距、
工作压力角、重合度、单双齿活动规则，以及内齿圈有限元轮缘柔度均保持不变。

模型采用彭悦《行星齿轮故障动力学模型与特征研究》第 3.2.1 节的直线齿根
裂纹假设：裂纹从齿根起始，裂纹长度为 `q_c`，与轮齿中心线夹角为 `gamma`。

## 截面与势能计算

在距齿根 `x` 的截面，健康齿厚为 `s_x=2 h_x`；根部半齿厚为 `h_c`。
令 `h_q=h_c-q_c sin(gamma)`，裂纹齿的有效截面按下式计算：

\[
s_{c,x}=\begin{cases}
2h_x,&h_x\le h_q\\
h_c+h_x-q_c\sin\gamma,&h_x>h_q
\end{cases}
\]

\[
A_{c,x}=B s_{c,x},\qquad I_{c,x}=\frac{B s_{c,x}^{3}}{12}.
\]

为避免数值上的零韧带，程序只在极限状态将 `s_c,x` 限制为健康截面的 5%。
这是数值保护，不是平滑或载荷转移模型。

将 `A_c,x`、`I_c,x` 分别代入原势能法的弯曲柔度和剪切柔度积分：

\[
C_b=\int_0^h\frac{[F_b(h-x)-F_a h]^2}{E I_{c,x}}\,dx,
\qquad
C_s=\int_0^h\frac{1.2F_b^2}{G A_{c,x}}\,dx.
\]

裂纹不直接改变齿廓接触线或齿根外部基础边界，因此轴向压缩柔度、齿根/轮缘
基础柔度、配对健康齿柔度以及 Hertz 柔度保持健康值。故障单对齿刚度仍由各项
柔度串联，双齿啮合时仍对活动齿对刚度直接并联。

## 行星轮的双啮合影响

当指定行星轮故障齿参与外啮合时，裂纹只进入 SP 对中该行星轮的 `C_b`、`C_s`；
当同一故障齿参与内啮合时，裂纹只进入 PR 对中该行星轮的 `C_b`、`C_s`。
两次事件的齿号和相位仍由现有真实运动学关系确定，不使用人为同步。

## 当前参数化案例

彭悦论文的代表参数为 `q_c=3 mm`、`gamma=45 deg`、模数 `m=5 mm`，即
`q_c/m=0.60`。为保持无量纲损伤程度，当前 `m=1.5 mm` 齿轮的对应中等仿真案例
设为 `q_c=0.90 mm`、`gamma=45 deg`；同时提供 0.45、0.90、1.35 mm 三个级别。
这些是论文仿真参数，尚不能标注为当前试验件的实测裂纹尺寸。

运行命令：

```powershell
.venv-tvms\Scripts\python.exe tvms\run_fault_tvms.py
```

或只计算一个案例：

```powershell
.venv-tvms\Scripts\python.exe tvms\run_fault_tvms.py --depth-mm 0.9
```
