# 真实双通道无转速计相位解耦结果

## 数据与盲测规则

数据文件为 `Sun0.50_600rpm_0.0A_test2_____25年03月28日182119.tdms`，共四列：

- 第1列：约 1.985 Hz 的行星架一转索引脉冲；
- 第2列：太阳轮 120 PPR 脉冲，约 595.6 rpm；
- 第3、4列：同步双通道振动；
- 采样率：51,200 Hz。

TDMS 中第1列并不是1024个可见脉冲/转。第1、2列在算法结束前不参与啮合频率、公共相位、
路径模型或正则参数估计，仅用于事后评分。振动盲估啮合频率为166.750 Hz，编码器均值为
166.796 Hz。

分析使用3–15 s记录，去除频带解析边缘后保留约11 s。啮合谐波为1、4、11、13阶。

## 真实数据促成的方法修正

完整空间阶次审计得到四个谐波的3k系数能量占比为：

- h=1：0.697；
- h=4：0.481；
- h=11：0.650；
- h=13：0.820。

因此理想的硬3k约束不适合作为最终模型。当前方法使用完整 `-12...12` 空间阶次，并对
非3k系数施加更强的岭惩罚。惩罚强度只用振动的奇偶行星架周期交叉验证选择，结果为30。
这对应“3k几何主子空间 + 可重复非对称残差”。

曾尝试用前后时段路径复现性估计平均频率修正，但盲目标的最优值落在搜索边界。安全判据
拒绝了该修正并回退到多谐波共模相位。这个结果说明公共路径绕数与平均转速相位仍存在
不可无条件分离的部分，不应使用编码器倒推参数后再称为无转速计算法。

## 最终量化结果

自适应三行星模型相对于编码器事后真值：

- 啮合相位RMSE：49.10°；
- 95%啮合相位误差：86.39°；
- 啮合频率RMSE：0.421 Hz；
- 行星架转速RMSE：0.301 rpm；
- 差模路径相位对完整编码器角度路径图RMSE：4.72°；
- 双通道动态相位残差：68.09°降至48.70°；
- 双通道相干性：0.563升至0.791；
- 解析分量幅值相对变化：`3.13e-16`。

自由空间模型的相干性为0.792，路径RMSE为4.20°；自适应模型以几乎相同的效果保留了
三行星几何先验。硬3k模型的相干性仅为0.640，说明非对称残差是必要项。

## 证据边界

当前文件只覆盖50%太阳轮断齿单一工况。它证明算法能在真实双通道记录上完成编码器隐藏
运行、相位估计、差模路径识别和相位单独补偿，但还不能证明故障识别率或跨工况泛化。
下一阶段需要健康、25%断齿和重复试验文件，使用同一冻结参数完成TPSVD/包络对比。
