# 健康参考冻结相位校正：预先固定的可行性协议

本协议在新实验指标计算前写入。初试只用同为 600 RPM 标称工况的 BL / PF50 各一条 60 s 记录；它不是跨试件或独立重复统计。

## 数据与分割

- 原始 Data 为 6,000,000 × 7、100 kHz；用第 1–3 列振动，布置按实验说明为 0/120/240 度。
- 工作副本降采样至 5120 Hz，只研究前四阶啮合谐波；原始数据不改动。
- 健康训练 [3,15) s，健康选型 [17,25) s。
- 故障 [3,15) s 只允许估计一个全记录共用角度偏置；同记录基线可用此段拟合相对相位，复杂度仍取健康选型结果。
- 两条记录的最终测试均为 [27,37)、[38,48)、[49,59) s；不根据这些指标修改模型。
- 啮合频率从每条记录 [3,15) s 的振动谱 145–190 Hz 内估计。前四阶解析分量使用有限长 0.5 s FIR；所有分割间隔大于局部滤波/平滑支撑。全记录连续积分仅用于保持角度坐标，不用测试段回拟训练模型。
- 编码器候选第 5/6 列只作最终验证。先检查两路解码一致性；报告载架角误差只消除一个常量，不消除漂移。编码器不是真实传递路径测量。

## 模型与选型

共同相位：所有传感器/四谐波的幅值可靠性加权相位增量融合，12 ms 平滑；共同相位先冻结，不交替回代路径拟合。

相对相位：健康训练段单位复互相位的带岭正则周期 Fourier 回归。候选常量、严格 3k 至 12 阶、自由 ±3/±6/±12 阶、非 3k 软惩罚 10/100（最高 12 阶）。常量候选用于区分固定相位旋转与真正周期路径收益。健康标定识别的是有效通道相对相位，不预先当作唯一真实结构传递函数。

候选传感器组合为全部三个及三种两两组合，使用固定参考传感器的星形连接；保存所有原始通道和校正前差分支路。只有健康选型平均相位一致性增益 ≥ 0.015、两个时间半段最差增益 ≥ −0.01 的组合才准入；最高验证一致性选中（按候选顺序打破平局）。若无准入项则不校正。

故障偏置用 [3,15) s、0–360 度的 3 度网格加局部一维细化估计；不逐谐波/逐周期调整。不更新健康系数。全三通道与选择组合分别冻结，避免把丢弃通道带来的收益归给相位算法。

## 对照和指标

对照包括全三通道共同相位、相同选择组合的共同相位、健康常量校正、健康冻结周期校正（全通道/选择组合）、仅在故障早期段拟合的同记录基线、三个单传感器。

1. 编码器参考载架角 RMSE、转速 RMSE，及第 5/6 列解码角一致性；仅减一个全记录常量相位偏置。
2. 加权瞬时通道相位一致性：时间/谐波平均的单位相位向量合成长度（0–1）。同时报告未加权值；全通道与选择组合不能直接视为纯校正增益。
3. 校正前差分包络、校正后公共包络、各单通道包络的阶次谱。载架域星轮单啮合故障阶次为 84/31，兼报 2 倍事件频率族。前四条理论谱线±0.18 阶峰值 RMS / 1–30 阶排除理论谱线±0.45 阶的中位背景，20 log10。这个量是相对谱线/背景，不是物理信噪比。
4. 幅值数值保持误差、冻结系数检查；总能量包络的相位旋转不变性作为数值测试，不作为诊断收益。

三个测试窗是同一条记录内的时间块，不给独立样本 p 值。暂定初筛：冻结周期校正测试相位一致性平均增益 ≥ 0.015，且 PF50 单/双事件频率族不比相同组合共同相位低 1 dB 以上。须另与常量校正及最好单通道比较；若只有常量改善，不能声称移动路径辨识有效。以上为工程筛查阈值，不是领域通用标准。

## 图契约

Python quantitative grid，183 × 130 mm；主证据是留出测试相位一致性和故障频率族变化，辅证据是共同相位对编码器的误差与公共/保留差分谱。导出 PNG、可编辑 SVG/PDF、600 dpi TIFF 和 CSV 源数据。每个点是一段 10 s 时间块，不绘制虚假的独立重复置信区间。负结果同样展示。

## 可辨识性边界

0/120/240 度的三点采样对 3k 空间分量具有同相混叠；不能因采用 3k 基函数就宣称解耦成功。共同路径相位与速度相位仍可能混淆，故障也会改变源混合。单对记录的健康参考迁移仅是可行性初试；模型失败应保留失败证据。

## 首轮结果之后追加的定位性对照（探索性，不重新充当独立验证）

首轮冻结测试暴露共同相位的明显累积漂移、公共包络频率族指标下降。保留首轮全部输出，另外仅运行两种共同相位对照，路径选型规则不变：

1. calibration_anchored：只用每条记录 [3,15) s 的共同相位估计相对振动谱啮合频率的线性漂移斜率，整条记录扣除此斜率；不使用编码器，不按故障诊断分数调参。这是在近恒速工况下的频率锚定，不是已证明的变转速跟踪方法。
2. nominal：完全用初始振动谱啮合频率作匀速相位，检验现有动态共同相位估计是否真的有收益。

两项对照共享已看过的留出测试窗，所以只能用于定位问题和生成下一轮假设，不能称新一轮盲测、独立确认或改变首轮筛查结论。
